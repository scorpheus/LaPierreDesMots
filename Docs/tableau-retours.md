# Tableau des retours — exercices et points à vérifier

Créé le 9 octobre 2026 à la demande du parent. **C'est Claude qui tient ce tableau à jour** : un
statut par ligne, les retours du parent consignés sous la ligne, datés. Le parent l'affiche
avec `/tableau` et dicte ses retours dans la conversation, en commençant par le numéro :
« E12 : … ». Les retours peuvent s'enchaîner et se mélanger ; le numéro suffit à les ranger.

## Comment tester

1. Lancer `demarrer.bat`. Il reconstruit le jeu si le code a changé, puis le sert sur
   `http://localhost:8080`.
2. Cliquer sur « ouvrir » à la ligne voulue. Le lien (`/debug/exercice?noeud=…`) ouvre l'exercice
   directement, **sans code ni choix du joueur**, pour le joueur retenu sur ce PC, et **hors journal** :
   la progression de l'enfant ne bouge pas. Ce raccourci ne marche que sur le PC lui-même
   (`localhost`) ; depuis la tablette, il ramène au jeu normal.
3. Dire ce qu'on voit : ce qui ne marche pas, ce qui est moche, ce qu'on ne comprend pas.

| Statut | Sens |
|---|---|
| 🟦 À tester | pas encore vu par le parent depuis le socle commun |
| ❓ Question / Dense | Claude a un doute ou une question, à regarder en priorité |

| 🟨 À vérifier | corrigé par Claude, le parent doit revoir |
| ✅ Validé | le parent a dit que c'est bon |
